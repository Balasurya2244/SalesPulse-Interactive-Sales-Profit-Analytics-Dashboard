# SalesPulse — Interactive Sales & Profit Analytics Dashboard

An interactive Power BI dashboard designed to analyze sales performance,
profitability, product performance, regional trends, and time-based sales
patterns.

## Project Overview

SalesPulse is a business intelligence project built using Microsoft Power BI
to transform raw sales data into meaningful and interactive business insights.

The dashboard provides an overview of:

- Total Sales
- Total Profit
- Total Quantity
- Product Performance
- Category Performance
- Regional Sales
- Monthly Sales Trends
- Day-wise Sales Performance

## Objectives

The main objectives of this project are:

1. Analyze overall sales performance.
2. Identify high-performing products.
3. Compare sales across product categories.
4. Analyze regional sales performance.
5. Understand monthly sales trends.
6. Compare sales performance across days of the week.
7. Provide an interactive dashboard for business decision-making.

## Dataset

The project uses a sales dataset containing 10,000 sales records.
